A set of 3rd party resources needed on my projects which would not be found any longer in the internet.

---

## NOTES

- The files provided in this repository where previously checked against possible **threats**
- We do not answer for any updates in the files provided here, if needed
  - In this case, submit an issue so the we can check the possibility / need of updating them.
- Everything from this repository is provided "as is", without any warranty, as the main intention of this, is to provide access to resources needed by our projects, when they may not be anymore find in the internet  

---

## TROUBLESHOOTING

In case any of the resources causes any problem or is not even anymore possible to be hosted, open an [issue](https://github.com/vonschappler-org-br/vonschappler-org-br.downloads/issues/new/choose) here.

We will do what is our reach to solve that, as long as the solution does not affect any of the 3rd party compliance / copyright rules, as this is just a redistribution repository.
